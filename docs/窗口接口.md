# 螺壳窗口的搜索页从螺壳搜索拿什么

> 另有侧栏里的应用页：`page/overview`（协议 §1a），写在这一页最后。

螺壳窗口的全局搜索（agent 工具协议 §1b）不经模型，直接调螺壳搜索的 `search_query`，把答复画成整页结果。这一页说清每一处从哪个字段来。对话里的结果卡片（`card`，A2UI）是另一回事，见协议 §4。

`scripts/check_agent.py` 用 agent 自己的客户端把这些字段走一遍，改了这里要跟着改它。

## 问

`search_query`，只读，不用点按：

| 参数 | 用在哪 |
|---|---|
| `query` | 搜索框里的字。不带字、只给 `since`/`until`、`kinds` 或 `sources` 时，列最新的。 |
| `sources` | 筛选按钮：`["files"]` 是"文件"，`["photos"]` 是"照片和视频"，不带就是"全部"。文件夹里的视频算 `files`，照片图库里的算 `photos`。 |
| `kinds` | 只要这几类（`doc`、`pdf`、`screenshot`、`image`、`video`、`audio`、`photo`）。 |
| `since`、`until` | ISO 8601 日期或时间；只有日期的算一整天，不带时区的按本机时间。 |
| `limit` | 1–50，默认 10。 |

查询的向量最多等 5 秒，过了就只按字词搜（`partial_reason` 会说，除非有更要紧的话要说，比如还在建索引），一般能赶在窗口的 10 秒以内答复。

## 答

`structuredContent`：

| 字段 | 画在哪 |
|---|---|
| `hits` | 结果的行：按分数从高到低；只按时间、只按类型列出的，最新的在前。 |
| `totals` | 筛选按钮和分段标题上的数（"文件 12"）：`{"files": n, "photos": m}`，两个来源总有值。它是一共对上几条，不受 `limit` 和 `sources` 限，所以点了"文件"以后"照片和视频"上的数不变。刚删、索引还没发现的文件会多算一条。 |
| `skipped` | 结果下面"照片还没允许搜 [允许]"那样的行，见下。总在，没有就是空列表。 |
| `partial`、`partial_reason` | 结果可能不全时的一句话（还在建索引、有的还在等向量……），可以放在页脚。 |
| `confident` | `false`：确定没找到；`null`：有结果，但说不准是不是答案。 |
| `card` | 对话里用的卡片，搜索页不用。 |

`content` 里的文字是给模型的，搜索页不用。

### 每一行（`hits[]`）

| 字段 | 画在哪 |
|---|---|
| `id` | 这一条的编号，按钮的参数都用它。条目还在索引里就不变。 |
| `title` | 标题：文件名，或照片图库里的原文件名（没有的叫"照片""视频"）。里面的凭证也遮了。 |
| `kind_label` | 这一类怎么叫（"截图""录音""照片"）。名字看不出类型时放在标题后面（"截图 · 10-05"）。 |
| `line` | 出处："第 3 页""第 2 部分""0:25"。说不出在哪的不带。 |
| `date` | 拍摄时间，没有就用修改时间，ISO 8601，例如 `2026-10-03T10:02:00+0800`。窗口自己决定显示成"10-03"还是"2025-10-02"。 |
| `snippet` | 对上的那一段，约 160 字，密码、卡号、证件号已遮。可能没有（只对上了文件名的、只按时间或类型列出的、没有字的图），这时不画这一行。 |
| `source` | `files` 或 `photos`：放进哪一段。 |
| `strong` | 搜索的第一条总是 `true`（找相似的不一定）。「最相关」取各来源排在前面的 strong 的。 |
| `thumb` | 有图的才带（图片、截图、照片、视频、PDF；SVG 和 AVFoundation 打不开的视频不带）：资源 `thumb/<编号>`，用 `resources/read` 读，答 JPEG，长边不超过 400。读不到时画占位框。 |
| `actions` | 这一行的按钮，见下。 |
| `kind`、`path`、`where`、`why`、`score` | 给模型和命令行用的，搜索页可以不看。 |

### 按钮（`actions[]`）

每个按钮是 `{name, title, args, primary?}`，`name` 是要调的工具，`args` 原样传回去。

| 按钮 | `name` | `args` | 说明 |
|---|---|---|---|
| 打开（primary） | `search_open` | `{id}` | 要带用户的点按（`ai.luoke/user-action`），没点不打开。 |
| 在访达中显示 | `search_open` | `{id, reveal: true}` | 只有文件有。画成文件夹图标也行。 |
| 找相似的 | `search_similar` | `{id}` | 只有已经算好向量的才有；只读，不用点按。 |

### 找相似的

`search_similar` 的答复和 `search_query` 一样（`hits`、`totals`、`skipped`、`card`），可以原地换掉结果，也可以画在那一行下面。它也认 `sources`。那条还没算出向量时 `hits` 为空，`partial_reason` 说明原因。

### 哪儿没搜（`skipped[]`）

每项是 `{source, why, text, detail, permission?}`：`text` 是那一行的字，`detail` 是下面的小字，都照原样画。

| `why` | 意思 |
|---|---|
| `needs_access` | 照片图库选了，用户还没让搜索读：没问过 macOS，或者收回了许可。这时**照片搜不到**：结果和 `totals` 都不算照片，`search_similar` 也一样，从照片那一条点进来答空的。读过的记录留在索引里，再允许以后不用重建 |
| `denied` | 拒绝过 |
| `not_updated` | 读过以后在系统设置里拒绝了，用户的许可还在：以前读过的照样搜得到，所以照片那一段**既有结果，又有这一行** |
| `off` | 设置里没开搜照片图库：按钮去螺壳搜索的设置 |

带 `permission` 的，按钮看那项权限现在的状态（§1a）。用户还没让搜索用这一项时，不管 macOS 给没给，都按 `ask` 算。照片在螺壳名下（清单 `owner: "luoke"`）：`ask` 画 [允许]，由螺壳自己在窗口里问，本工具没有申请动作；`denied` 时 macOS 不会再问，不画 [允许]，可以画 [去系统设置]（`search_open_system_settings`，`{pane: "photos"}`）。

只要 `files`（`sources: ["files"]`）或只要照片图库没有的类型时，不列照片图库。

## 和本体说话（描述符 3）

本体给的 `LUOKE_HOST_FD`（现在是 3）是一条写给本体的管道，一行一个 JSON：

| 这一行 | 什么时候说 | 本体做什么 |
|---|---|---|
| `{"up": true}` | 常驻程序的工具 socket 起好以后，说一次 | 重起它以后等这句话，再转等着的活；本体最多等 20 秒 |
| `{"play": 路径, "at": 秒}` | 用户要从某一刻放音视频 | 用户刚点过就用 QuickTime 从那一刻放（自动化权限在螺壳名下），否则只打开文件。只放存在的绝对路径上的音视频 |

## 应用页（`page/overview`）

侧栏「应用」下的页，清单 `service.pages` 里写了 `overview`（概览），和扫描一样走协议 §1a。螺壳搜索开着才有这一行。

- 内容：一张列表，左边名字，右边数值：精确搜索、语义搜索（可用，或进度条和数字，`ProgressBar` 组件；语义搜索用不了时写等待下载、稍后可用、未连接、不支持）、文件夹、搜照片图库（开关；开着但没允许时，开关左边多一个按钮：没问过是「允许」，拒绝过是「去系统设置」。按钮的 context 带 `permission: photos`，窗口交给螺壳本体）、最近读入。暂停了或有文件不在这台 Mac 上，两行状态下面多一行小字。进度是读这一页那一刻的。文件夹只写名字；最近读入只有时间，没有文件名，也没有搜过什么。
- 开关是 `variant: switch`、带 `on` 的 Button（不认识的窗口画成普通按钮，字是「也搜照片」「不再搜照片」），打开时 context 带 `needs: photos`（窗口先交给螺壳要权限，够了才调），调 `search_settings_apply`，不带 `plan_id`，带 `{photos}`。只认这一页上的点按（`surfaceId` 是 `overview`）。
- 这一版文件夹只显示，不能在这里改。
- 没有「用电池时建索引」的开关：连着螺壳时听螺壳的电池设置，这个设置不起作用。
