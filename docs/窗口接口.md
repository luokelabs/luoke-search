# 螺壳窗口的搜索页从螺壳搜索拿什么

> 另有侧栏里的应用页：`page/overview`（协议 §1a），写在这一页最后。

螺壳窗口的全局搜索（agent 工具协议 §1b）不经模型，直接调螺壳搜索的 `search_query`，把答复画成整页结果。这一页说清每一处从哪个字段来。对话里的结果卡片（`card`，A2UI）是另一回事，见协议 §4。

`scripts/check_agent.py` 用 agent 自己的客户端把这些字段走一遍，改了这里要跟着改它。

## 问

`search_query`，只读，不用点按：

| 参数 | 用在哪 |
|---|---|
| `query` | 搜索框里的字。不带字、只给 `since`/`until`、`kinds` 或 `sources` 时，列最新的。 |
| `sources` | 筛选按钮：`["files"]` 是"文件"，`["photos"]` 是"照片和视频"，不带就是"全部"。文件夹里的视频算 `files`，照片图库里的算 `photos`。 |
| `kinds` | 只要这几类（`doc`、`pdf`、`screenshot`、`image`、`video`、`audio`、`photo`）。 |
| `since`、`until` | ISO 8601 日期或时间；只有日期的算一整天，不带时区的按本机时间。 |
| `limit` | 1–50，默认 10。 |

查询的向量最多等 5 秒，过了就只按字词搜（`partial_reason` 会说，除非有更要紧的话要说，比如还在建索引），一般能赶在窗口的 10 秒以内答复。

## 答

`structuredContent`：

| 字段 | 画在哪 |
|---|---|
| `hits` | 结果的行：按分数从高到低；只按时间、只按类型列出的，最新的在前。 |
| `totals` | 筛选按钮和分段标题上的数（"文件 12"）：`{"files": n, "photos": m}`，两个来源总有值。它是一共对上几条，不受 `limit` 和 `sources` 限，所以点了"文件"以后"照片和视频"上的数不变。刚删、索引还没发现的文件会多算一条。 |
| `skipped` | 结果下面"照片还没允许搜 [允许]"那样的行，见下。总在，没有就是空列表。 |
| `partial`、`partial_reason` | 结果可能不全时的一句话（还在建索引、有的还在等向量……），可以放在页脚。 |
| `confident` | `false`：确定没找到；`null`：有结果，但说不准是不是答案。 |
| `card` | 对话里用的卡片，搜索页不用。什么都没找到时，卡片上（和给模型的文字里）多一行找过哪些文件夹、可以跟螺壳说要搜别的（`sources` 只要照片图库时不说）。 |

`content` 里的文字是给模型的，搜索页不用。

### 每一行（`hits[]`）

| 字段 | 画在哪 |
|---|---|
| `id` | 这一条的编号，按钮的参数都用它。条目还在索引里就不变。 |
| `title` | 标题：文件名，或照片图库里的原文件名（没有的叫"照片""视频"）。里面的凭证也遮了。文件名是百分号编码存的（下载工具常这样留：`%E5%8F%91%E7%A5%A8.pdf`），解得出能显示的字就给解码后的（「发票.pdf」）；`path` 和打开照旧用原名。 |
| `kind` | 按类型分组用：`pdf`、`sheet`（表格：xlsx、csv、tsv）、`doc`、`image`、`screenshot`、`photo`、`video`、`audio`。`sheet` 只在这里有：索引里表格还算 `doc`，`search_query` 的 `kinds` 筛选也照旧（筛 `doc` 包括表格）。 |
| `kind_label` | 这一类怎么叫（"截图""录音""照片""表格"）。名字看不出类型时放在标题后面（"截图 · 10-05"）。 |
| `line` | 出处："第 3 页""第 2 部分""0:25"。说不出在哪的不带。 |
| `date` | 拍摄时间，没有就用修改时间，ISO 8601，例如 `2026-10-03T10:02:00+0800`。窗口自己决定显示成"10-03"还是"2025-10-02"。 |
| `snippet` | 对上的那一段，约 160 字，密码、卡号、证件号已遮。可能没有（只对上了文件名的、只按时间或类型列出的、没有字的图），这时不画这一行。 |
| `source` | `files` 或 `photos`：放进哪一段。 |
| `strong` | 这一条本身就很对得上，不看它排第几：要找的字都在文件名（不算扩展名和上面的文件夹）或照片的标题里，或者意思很近（量出来的门槛，见 `evals/README.md`「很有把握」）。可能一条都没有；只按时间、类型列出最新的时都是 `false`。「最相关」取各来源排在前面的 strong 的。找相似的另算（意思够突出）。 |
| `thumb` | 有图的才带（图片、截图、照片、视频、PDF、表格；SVG 和 AVFoundation 打不开的视频不带）：资源 `thumb/<编号>`，用 `resources/read` 读，答 JPEG，长边不超过 400。PDF 对上了某一页时是那一页（`thumb/<编号>-p3`）；表格是对上的那个工作表的前几行（`thumb/<编号>-w2`，不知道哪个工作表时画第一个），表头在上，密码那一列、卡号照片段的规矩遮。读不到时画占位框。 |
| `actions` | 这一行的按钮，见下。 |
| `path` | 全路径；窗口自己取最后一两层文件夹。 |
| `where`、`why`、`score` | 给模型和命令行用的，搜索页可以不看。 |

### 按钮（`actions[]`）

每个按钮是 `{name, title, args, primary?}`，`name` 是要调的工具，`args` 原样传回去。

| 按钮 | `name` | `args` | 说明 |
|---|---|---|---|
| 打开（primary） | `search_open` | `{id}` | 要带用户的点按（`ai.luoke/user-action`），没点不打开。 |
| 在访达中显示 | `search_open` | `{id, reveal: true}` | 只有文件有。画成文件夹图标也行。 |

结果上只放这两样：agent 工具协议 §1b 定了结果上的按钮点了只回一句话，窗口不画工具答回来的结果。

### 找相似的

不是结果上的按钮（2026-11-10 拿掉：点了窗口不画答回来的结果，看着像没反应）。工具 `search_similar` 还在，给 agent 自己用：按结果的 `id` 调，答复和 `search_query` 一样（`hits`、`totals`、`skipped`、`card`），也认 `sources`。那条还没算出向量时 `hits` 为空，`partial_reason` 说明原因。以后窗口要能原地换掉结果，再放回结果上。

### 哪儿没搜（`skipped[]`）

每项是 `{source, why, text, detail, permission?}`：`text` 是那一行的字，`detail` 是下面的小字，都照原样画。

| `why` | 意思 |
|---|---|
| `needs_access` | 照片图库选了，用户还没让搜索读：没问过 macOS，或者收回了许可。这时**照片搜不到**：结果和 `totals` 都不算照片，`search_similar` 也一样，从照片那一条点进来答空的。读过的记录留在索引里，再允许以后不用重建 |
| `denied` | 拒绝过 |
| `not_updated` | 读过以后在系统设置里拒绝了，用户的许可还在：以前读过的照样搜得到，所以照片那一段**既有结果，又有这一行** |
| `off` | 设置里没开搜照片图库：按钮去螺壳搜索的设置 |

带 `permission` 的，按钮看那项权限现在的状态（§1a）。用户还没让搜索用这一项时，不管 macOS 给没给，都按 `ask` 算。照片在螺壳名下（清单 `owner: "luoke"`）：`ask` 画 [允许]，由螺壳自己在窗口里问，本工具没有申请动作；`denied` 时 macOS 不会再问，不画 [允许]，可以画 [去系统设置]（`search_open_system_settings`，`{pane: "photos"}`）。

只要 `files`（`sources: ["files"]`）或只要照片图库没有的类型时，不列照片图库。

## 和本体说话（描述符 3）

本体给的 `LUOKE_HOST_FD`（现在是 3）是一对 socketpair 的一端，一行一个 JSON。

启动时先认本体（`FromApp`，发布版里除了 `status` 和帮助都这样），按这个顺序：

1. 描述符 3 是 Unix stream socket；
2. 通道那头（`LOCAL_PEERPID`：最后读写那一头的进程）是父进程，而且父进程**这一刻**跑的是同一个 .app 的主程序：按内核给的 audit token（`LOCAL_PEERTOKEN`）核它正在跑的程序的签名，要苹果签发、和搜索同一个团队、标识是 .app 的 `CFBundleIdentifier`；程序文件是 `Contents/MacOS/<CFBundleExecutable>`；
3. 这以后才写一行 `{"id":"<16 字节随机数>","method":"hello"}`，5 秒内要读到一行答复，`id` 要一样；
4. 答完以后那头还是父进程，audit token 里的 pid version（exec 一次就变）和第 2 步时一样。

不是就退出码 77，一句「不是螺壳起的（原因）」。顺序是有讲究的：对端的 audit token 是「取的那一刻」这个 pid 上跑的程序的，不是写那一行时的（macOS 27 上量过）。要是答完才核，父进程可以先自己答、再 exec 成主程序（pid 不变）就过了。现在父进程在有东西可答以前就得已经是主程序；答复要带新随机数，不能事先写好；父进程留下别的进程来答，那头记的就是那个进程。本体那边不用多做：带 `id` 的请求，它原样带回 `id`。

常驻的那次，本体对 hello 的答复里带口令：`{"id":"<同一个 id>","result":{"status":"ok","token":"…"}}`（每次起都新生成，不进参数、环境变量、文件）。
发布版的工具 socket 只认 `params._meta["ai.luoke/token"]` 是这个口令的请求，读的也一样；没带或不对答 JSON-RPC 错误 `-32001`「口令不对」，
在执行任何东西之前。本体没给口令就谁来都拒。agent 核心经本体的通道要这个口令（agent 的 `docs/界面接口.md` §15）。开发版不看口令。

本体单独跑的 `settings` 也有描述符 3（不设 `LUOKE_HOST_FD`），只用来认本体，认完就关。带 `id` 的行是请求，本体就地答；不带的是下面这些：

| 这一行 | 什么时候说 | 本体做什么 |
|---|---|---|
| `{"up": true}` | 常驻程序的工具 socket 起好以后，说一次 | 重起它以后等这句话，再转等着的活；本体最多等 20 秒 |
| `{"play": 路径, "at": 秒}` | 用户要从某一刻放音视频 | 用户刚点过就用 QuickTime 从那一刻放（自动化权限在螺壳名下），否则只打开文件。只放存在的绝对路径上的音视频 |

## 应用页（`page/overview`）

侧栏「应用」下的页，清单 `service.pages` 里写了 `overview`（概览），和扫描一样走协议 §1a。螺壳搜索开着才有这一行。

- 内容：一张列表，左边名字，右边数值：精确搜索、语义搜索（可用，或进度条和数字，`ProgressBar` 组件；语义搜索用不了时写等待下载、稍后可用、未连接、不支持）、文件夹（几个，下面每个一行；外接盘也在这里）、搜照片图库（开关；开着但没允许时，开关左边多一个按钮：没问过是「允许」，拒绝过是「去系统设置」。按钮的 context 带 `permission: photos`，窗口交给螺壳本体）、最近读入。暂停了或有文件不在这台 Mac 上，两行状态下面多一行小字。进度是读这一页那一刻的。文件夹只写名字（凭证遮住）；最近读入只有时间，没有文件名，也没有搜过什么。
- 开关是 `variant: switch`、带 `on` 的 Button（不认识的窗口画成普通按钮，字是「也搜照片」「不再搜照片」），打开时 context 带 `needs: photos`（窗口先交给螺壳要权限，够了才调），调 `search_settings_apply`，不带 `plan_id`，带 `{photos}`。只认这一页上的点按（`surfaceId` 是 `overview`）。
- 文件夹一个一行（最多 20 行，再多写还有几个、在对话里说；同名的后面带上一级的名字），每行右边一个「不搜了」：调 `search_settings_apply`，不带 `plan_id`，带 `{folder: 编号}`（context 里写死的；编号是存着的路径算出来的，页上哪儿都不出路径）。只认这一页上的点按，一次一个，和 `photos` 一起给就拒；不再确认，马上执行：设置里去掉，索引里那个文件夹的条目马上删，答一句「不再搜「…」了…」（在另一个要搜的文件夹里面时，说照样搜得到）。还没选过要搜的地方时没有这个按钮。
- 外接盘（11-10 起）：选了的盘和文件夹列在一起（名字是盘名，没接上时后面写「（没接上）」），「不搜了」一样带 `{folder: 编号}`；接着、没选的盘列在「外接盘 · 默认不搜」下面（最多 3 块），每块一个「也搜这块盘」：带 `{disk: 盘的 UUID}`。只列本机的、不是内置的、能写的、在 `/Volumes` 下的盘：网络盘、装软件的磁盘映像、Time Machine 的不列。点了以后，第一次读盘时 macOS 会问让不让读「可移除的宗卷」（谁来问还要和螺壳本体对，见 STATUS）。
- 个人文件夹里（11-10 起，个人文件夹在搜时才有）：个人文件夹里直接放着的、会读的文件夹一个一行（桌面、文稿、下载、图片、影片在前，最多 10 行），每行一个「跳过」，带 `{skip: 编号}`；跳过的列在「跳过的」下面（最多 6 行），每行一个「不跳过了」，带 `{unskip: 编号}`。只读个人文件夹本身的列表，不看桌面、文稿、iCloud 云盘里面（打开这一页时 macOS 不会因此问用户）。跳过的那个文件夹的条目在下一遍走过时移出索引。
- 这些按钮和「不搜了」一样：只认这一页上的点按，一次一个，不再确认。
- 这一版还不能在这里加别的文件夹（「添加文件夹…」要窗口和螺壳本体先能弹出选文件夹的窗口）；默认已经搜整个个人文件夹，要加的多是外接盘上的。
- 没有「用电池时建索引」的开关：连着螺壳时听螺壳的电池设置，这个设置不起作用。
